# 章ドキュメント・練習問題の執筆ルール

## 章のドキュメント構成

各章の `docs/chapterXX.md` は以下の構成で統一する。

```
# XX章 タイトル

## このチャプターで学ぶこと
（箇条書き：3〜5項目）

## 基礎知識
（概念の説明・図・コード例。演習ではなく読み物）

## スターターコードの確認
（どのファイルを見れば良いか・現状の動作説明）
※ フェーズ2（ch07〜08）はスキップ

## 練習問題
### 問題 XX-1
### 問題 XX-2
...
```

## 練習問題の設計方針

### フェーズ 1（ch01〜06）の問題形式

- **問題の前半**：既存コードに対する「仕様変更」（表示するカラムを増やす・並び順を変える等）
- **問題の後半**：「機能追加」（新しいボタン・フォームの追加等）
- 1章あたり 4〜6 問。難易度は問題番号が上がるにつれ少しずつ上がる
- 各問題には「ヒント」と「確認ポイント」（期待する動作）を記載する

### フェーズ 2（ch07〜08）の問題形式

- **仕様書形式**：「〜の画面を作ること」という要件を箇条書きで提示
- 実装すべき機能・URL・表示内容・バリデーション条件を明示する
- ヒントは最小限にし、自力で調べながら実装する力を養う

### 問題設計の原則

- 1問で学ぶことは 1 つに絞る（複数の概念を同時に導入しない）
- 問題文には「どのファイルを編集するか」を必ず明記する
- コードをゼロから書かせるより「ここを直す・ここを追加する」形式を優先する（フェーズ 1）
- エラーメッセージの読み方・デバッグ方法も問題の中で触れる

## ドキュメント執筆時の注意事項

- 専門用語は初出時に日本語で説明する
- コード例には必ず「どこに書くか（ファイルパス）」を示す
- 「なぜそう書くか」の理由を省かない（暗記させない）
- tokkun-java / tokkun-sql で学んだ概念は「〜で学んだ〇〇と同じです」と明示して接続する
- 図（テキストアート・Mermaid）を積極的に使い、HTTP の流れや MVC の関係を可視化する

## Java / Spring 特有の説明ルール

### アノテーションの初出説明

アノテーションが初めて登場する章では、その役割を必ず説明する。

| アノテーション | 初出章 | 説明すべき内容 |
|---|---|---|
| `@Controller` | ch01 | クラスをコントローラとして登録する印 |
| `@GetMapping` / `@PostMapping` | ch01 / ch03 | URL と HTTP メソッドをメソッドに対応づける |
| `@PathVariable` | ch02 | URL の `{id}` 部分を引数に受け取る |
| `@RequestParam` | ch06 | クエリパラメータ（`?keyword=...`）を引数に受け取る |
| `@ModelAttribute` | ch03 | フォームの入力値をオブジェクトにまとめて受け取る |
| `@Valid` | ch04 | バリデーションを実行するトリガー |
| `@NotBlank` / `@Range` 等 | ch04 | Bean Validation のバリデーションルール |

### Thymeleaf 属性の初出説明

| 属性 | 初出章 | 説明すべき内容 |
|---|---|---|
| `th:each` | ch01 | コレクションを繰り返し表示する（Java の for-each と同じ） |
| `th:text` | ch01 | タグの中身を変数で置き換える |
| `th:href` | ch01 | リンク先 URL を動的に生成する |
| `th:action` | ch03 | フォームの送信先 URL を指定する |
| `th:object` / `th:field` | ch03 | フォームとモデルオブジェクトを紐づける |
| `th:errors` | ch04 | バリデーションエラーメッセージを表示する |
| `th:if` / `th:unless` | ch02 | 条件によって表示を切り替える |

### 「tokkun-java / tokkun-sql で学んだこと」との接続例

- `JdbcTemplate.query()` の行マッピング → 「tokkun-java で学んだラムダ式・Stream API の応用です」
- `th:each` → 「tokkun-java ch04 の for-each ループと同じ考え方です」
- バリデーション条件の確認 → 「tokkun-sql ch02 の WHERE 句で書いた条件と同じロジックです」
- `MapSqlParameterSource` のパラメータ渡し → 「tokkun-sql ch02 で学んだプレースホルダ（`$1`）の Java 版です」
